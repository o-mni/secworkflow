RRECOVER

  • Confirm clean endpoint scan before restoring full access
  • Document IOCs and push to threat intel blocklist
  • Send targeted awareness note to affected users

Malware EDR Alert C2 Beacon

CRITICAL

Lateral Movement
PtH / PtT SMB Spread Domain Escalation
D C E R
CRITICAL
DDETECT
  • Abnormal SMB/RDP/WMI/WinRM auth between workstations
  • Admin share access (C$, ADMIN$) from non-admin hosts
  • Events 4648 (explicit creds) / 4624 Type 3 at scale
  • New admin accounts or unexpected group membership changes
CCONTAIN
  • Segment network — isolate the affected VLAN/subnet now
  • Block SMB 445 / RDP 3389 between endpoints at switch level
  • Disable all accounts involved in the movement chain
  • Reset KRBTGT password twice if Kerberos ticket abuse suspected
EERADICATE
  • Identify patient zero — trace movement back to initial compromise
  • Map full blast radius — every system reached must be treated as infected
  • Hunt persistence on every system in the movement chain
  • Find and remove credential dumping artifacts (Mimikatz, etc.)
RRECOVER
  • Rebuild all compromised systems from clean images
  • Rotate ALL privileged credentials org-wide
  • Implement LAPS for local admin password management
  • Re-enable connectivity incrementally with enhanced monitoring

🔍Recon Checklist
Passive Recon
  • WHOIS / DNS enumeration — nslookup, dig, dnsx, amass
  • Shodan / Censys / FOFA for exposed services and banners
  • Google dorks: site: filetype: inurl: intitle: "index of"
  • Certificate transparency: crt.sh for subdomain enumeration
  • OSINT: LinkedIn (employees, tech stack), job postings, GitHub
  • theHarvester, SpiderFoot for email + org mapping
  • ASN / BGP: bgp.he.net, ipinfo.io — identify IP ranges
Active Recon
  • nmap -sV -sC -A -T4 -oA scan <target>
  • nmap -p- --min-rate 5000 <target> — all ports fast
  • Subdomain brute: ffuf -w wordlist -u https://FUZZ.target.com
  • Directory brute: gobuster dir -u url -w /usr/share/wordlists/dirbuster/medium.txt
  • Banner grab: nc -v host port or curl -sI url

🌐Web Testing — OWASP Top 10
  • A01
    Broken Access Control — IDOR, forced browsing, missing auth on API endpoints, horizontal + vertical privilege escalation
  • A02
    Cryptographic Failures — HTTP without TLS, weak ciphers, sensitive data in URL or logs, hardcoded keys in source
  • A03
    Injection — SQL, command, LDAP, XPath injection in all user-controlled params (headers, cookies, body)
  • A04
    Insecure Design — No rate limiting, missing business logic controls, predictable tokens, insecure direct object references
  • A05
    Security Misconfiguration — Default creds, verbose errors, directory listing, exposed admin UI, unnecessary features enabled
  • A06
    Vulnerable Components — Outdated libraries, unpatched CMS, vulnerable dependencies — check known CVEs
  • A07
    Auth Failures — Brute force, credential stuffing, weak session tokens, no account lockout, no MFA
  • A08
    Data Integrity Failures — Unverified deserialization, unsigned software updates, insecure CI/CD pipelines
  • A09
    Logging Failures — Test if attacks trigger alerts, check log injection via user input fields
  • A10
    SSRF — Cloud metadata (169.254.169.254), internal probing via URL parameters, DNS rebinding
⚡Attack Indicators & Payloads
SQL Injection
  • ' OR '1'='1 — basic auth bypass test
  • ' UNION SELECT null,null,null-- — column enum
  • ' AND SLEEP(5)-- / '; WAITFOR DELAY '0:0:5'-- — time-based
  • Error keywords: syntax error, ORA-, MySQL, pg_query, SQLSTATE
  • sqlmap -u "http://target/page?id=1" --dbs --batch
Cross-Site Scripting (XSS)
  • <script>alert(document.domain)</script>
  • "><img src=x onerror=alert(1)>
  • javascript:alert(document.cookie) — in href/src fields
  • DOM XSS: look for document.location, innerHTML, eval(), document.write()
Linux Privilege Escalation
  • sudo -l — commands allowed without password
  • find / -perm -4000 2>/dev/null — SUID binaries
  • crontab -l && cat /etc/cron* — writable scripts?
  • LinPEAS / LinEnum — automated enumeration · GTFOBins for escapes
Windows Privilege Escalation
  • whoami /priv — SeImpersonatePrivilege → Potato attacks
  • winPEAS.exe / PowerUp.ps1 — automated enum
  • Unquoted service paths, weak service binary ACLs
  • reg query HKCU\SOFTWARE\Policies\Microsoft\Windows\Installer /v AlwaysInstallElevated

Logs & Investigation Helper

What to check first, what normal looks like, and quick filter patterns.

🔑Authentication Logs
Windows Security Event Log
  • 4624 Successful logon — check Type (3=network, 10=remote interactive)
  • 4625 Failed logon — spike = brute force or stuffing
  • 4648 Explicit credential use — Pass-the-Hash indicator
  • 4672 Special privileges assigned to new logon
  • 4720 New user account created
  • 4768/4769 Kerberos TGT/TGS — AS-REP / Kerberoasting?
  • 4776 NTLM auth — why not Kerberos?
Linux Auth
  • /var/log/auth.log — SSH, sudo, su (Debian/Ubuntu)
  • /var/log/secure — auth on RHEL / CentOS
  • journalctl -u sshd --since "2 hours ago"
  • last -n 30 | grep -v "wtmp" — recent logins
✓ Normal: 1–3 logins/day from consistent IPs + user agents
✗ Suspicious: 50+ failures then success · Off-hours admin · New geo · 2 concurrent IPs
🌐Network / Firewall Logs
Key Indicators
  • Connections to known malicious IPs/domains (threat intel feed)
  • Traffic on unusual ports: 4444, 1337, 8888, high ephemeral ports
  • Large outbound data volumes during off-hours
  • Beaconing: periodic outbound at consistent intervals (±few secs)
  • Internal scanning: high-volume SYN to many hosts (worm / lateral recon)
  • Connections to TOR exit nodes or anonymizer proxies
Quick Filter Examples
  • Splunk: index=firewall action=blocked | stats count by src_ip | sort -count
  • Elastic: event.category:network AND NOT destination.port:(80 OR 443)
  • grep "DENY" fw.log | awk '{print $5}' | sort | uniq -c | sort -rn | head -20
✓ Normal: HTTP/S to known CDNs, internal AD/DNS, NTP sync
✗ Suspicious: Port 4444 · TOR IPs · Fixed-size payloads · Outbound at 3am to unknown ASN
🔎DNS Logs
Indicators in DNS
  • Queries to recently registered domains (under 30 days)
  • DGA-like domains: random character strings with high entropy
  • DNS tunneling: subdomains over 50 chars long (data in subdomain)
  • NXDOMAIN storm from single host — DGA malware C2 lookups
  • High query volume to a single external domain
  • TXT record queries at high frequency (data exfil via DNS)
Quick Patterns
  • grep NXDOMAIN dns.log | awk '{print $6}' | sort | uniq -c | sort -rn | head -20
  • grep -E "[a-z0-9]{30,}\." dns.log — long subdomain (tunnel/DGA)
  • High entropy check: subdomains with length > 30 chars
✓ Normal: A/AAAA for known domains, low NXDOMAIN rate (<1%)
✗ Suspicious: 100s of NXDOMAIN · Base64 subdomains · .bit / .onion lookups · TXT flood
💻Endpoint / EDR (Sysmon)
Key Sysmon Event IDs
  • Event 1 Process create — inspect parent/child relationship
  • Event 3 Network connection from process — beacon detection
  • Event 7 Image/DLL loaded — DLL hijacking detection
  • Event 8 CreateRemoteThread — process injection indicator
  • Event 10 Process access (lsass.exe = credential dump)
  • Event 11 File created — dropper artifacts
  • Event 13 Registry value set — persistence mechanism
Suspicious Process Chains
  • WINWORD.EXE → cmd.exe — macro execution
  • excel.exe → powershell.exe — macro payload
  • svchost.exe → cmd.exe — service abuse
  • powershell.exe → net.exe / whoami.exe — post-exploit recon
  • mshta.exe → wscript.exe — HTA dropper chain
✓ Normal: explorer.exe → chrome.exe · services.exe → svchost.exe
✗ Suspicious: Office → cmd/PS · lsass read by unknown binary · rundll32 outbound

Governance, Risk & Compliance

Quick reference — practical reminders for ops and audit mindset.

Risk Fundamentals
RISK = LIKELIHOOD × IMPACT
Likelihood ↓ / Impact → LowMediumHigh
High Medium High Critical
Medium Low Medium High
Low Low Low Medium
Asset Classification
  • PUBLIC
    Marketing site, press releases, public APIs. No special controls. Treat as hostile perimeter.
  • INTERNAL
    Intranet, internal tools, employee docs. Require authentication and basic access control.
  • CONFIDENTIAL
    Customer data, financials, HR records. Restricted access + encryption at rest and in transit.
  • RESTRICTED
    Trade secrets, PII, regulated data. Highest controls required. Full audit trail mandatory.
Audit Mindset
  • 📝
    Logging — Who did what, when, from where? Are logs centralized and tamper-proof?
  • 🔗
    Traceability — Can every system action be tied to a specific identity?
  • 🔒
    Access Control — Least privilege enforced. Who has access they shouldn't?
  • 🔄
    Change Management — Are changes reviewed, approved, and logged with justification?
  • 🧪
    Testing — Are controls actually tested, not just documented? Evidence of testing?
  • 📅
    Review Cadence — Access reviews, policy updates, pen tests — scheduled and completed?
Regulatory Quick Notes
  • GDPR
    Breach → supervisory authority within 72 hours
    Notify individuals if high risk. Maintain a breach register. Art. 33/34.
  • NIS2
    Significant incident → 24h early warning, 72h full notification
    EU essential + important entities. Covers IT and OT systems.
  • ISO 27001
    Key Annex A: A.8 (assets), A.9 (access), A.12 (ops), A.16 (incidents)
    Risk-based. Controls must be implemented AND evidenced with records.
  • NIST CSF
    Functions: Govern → Identify → Protect → Detect → Respond → Recover
    CSF 2.0 added Govern. Tiers 1–4 indicate maturity level.
  • DORA
    EU financial sector. ICT incident: notify within 4h of classification
    TLPT (threat-led pen testing) required for significant firms.
